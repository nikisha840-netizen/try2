# Приглашение на гендер-пати

Готовый статический сайт. Не требует ChatGPT, сборки и установки пакетов. Анимации и иллюстрации находятся внутри index.html. Для загрузки шрифтов нужен интернет; при недоступности шрифтов используются системные.

## Публикация через GitHub Pages

1. Создай публичный репозиторий, например `gender-party`.
2. Распакуй архив и загрузи файлы `index.html`, `.nojekyll` и `README.md` в корень репозитория: Add file → Upload files → Commit changes. Загружай файлы, а не сам ZIP.
3. Открой Settings → Pages.
4. В Source выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), нажми Save.
6. Дождись публикации. Рабочая ссылка появится в Settings → Pages, кнопка Visit site.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Редактирование

Текст, оформление и анимации меняются в index.html. Календарное событие встроено в ссылку «Добавить в календарь».
